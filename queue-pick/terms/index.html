서비스 범위

창업지원금 공고은 정부기관이 운영하는 서비스가 아닌 독립적인 참고 도구예요. 공식 창업지원 공고를 탐색하고 개인 지원 준비 상태를 관리하는 도구이며, 공식 자격·선정·지급을 확정하거나 신청을 대행하지 않아요. 공식기관의 최신 기준과 개별 안내를 먼저 확인해요.

기기에서 처리하는 정보

관심 지역·창업 단계·만 업력·분야와 직접 표시한 준비 상태는 기기에서만 처리해요. 저장을 선택한 보드만 기기에 남고 저장 해제로 지울 수 있어요. 공개 공고 갱신은 GitHub의 공개 정적 데이터에 조건을 붙이지 않고 요청해요. 갱신 요청 과정의 접속 정보는 GitHub의 정책에 따라 처리될 수 있어요. 기기 입력값은 이 요청에 첨부하지 않아요. 입력 원자료를 운영 서버·광고·분석 이벤트에 넣어 보내지 않아요. 기존 다른 기능의 저장 키는 변경하지 않아요.

광고와 이용 이벤트

공식 제도 안내와 출처는 무료로 볼 수 있어요. 보상과 조건을 확인하고 리워드 광고 시청을 선택할 수 있으며, SDK 시청 완료 보상이 확인된 경우에만 상세 기능이 열려요. 광고 중도 종료·클릭·표시 실패만으로 열리지 않아요. 배너와 보상형 광고, 일반 버튼·완료 이벤트를 사용할 수 있어요.

외부 플랫폼

앱인토스·토스 광고 SDK는 광고 식별자, 기기·접속·광고 이벤트 정보를 자체 정책에 따라 처리할 수 있어요. 사용자가 입력한 조건·날짜·금액·출석 원자료는 광고 또는 이용 이벤트에 첨부하지 않아요. 공식 출처를 열면 해당 사이트의 정책이 적용돼요.

정보 최소화와 보관

이름·주민등록번호·계좌번호 등 직접 식별 정보를 요구하지 않아요. 자유 입력에는 서비스에 필요한 과정명 등만 쓰고 개인 식별 정보는 넣지 말아 주세요. 기기 기록은 저장 해제 또는 앱·브라우저 저장소 정리 전까지 남을 수 있고, 기기 정리·교체 시 복원되지 않을 수 있어요.

문의와 이용자의 권리

정보 처리 또는 서비스 문의는 help@paran.app으로 보내 주세요. 문의에 사용자가 직접 제공한 이메일과 내용은 답변·문제 해결에 사용하며, 목적 달성 뒤 관련 법령상 보존이 필요한 경우를 제외하고 정리해요. 선택적 기기 저장을 해제하고도 무료 안내를 사용할 수 있어요.

서비스의 변경과 정확성

공식 제도와 플랫폼 변경에 맞춰 기능·기준을 수정할 수 있어요. 기준일과 적용 범위를 화면에서 확인해 주세요. 입력 오류·정산·행정 처리 차이를 고려해 실제 행동 전 공식기관에서 확인해요. 이 안내는 법령상 이용자의 권리를 제한하지 않아요.
