지원금 자부담표
개인정보처리방침

시행일 2026년 10월 17일

서비스 범위

지원금 자부담표는 정부·공공기관과 제휴하지 않은 독립적인 사업비 계획 모의 도구예요. 사용자가 해당 공고·협약에서 직접 확인한 총사업비 기준 비율·계산 단위와 요청 지원금·준비 가능한 현금·현물 항목을 입력해 정부지원·현금·현물 구성을 계획해요. 지원 자격·지역 분류·사업 선정·현물 인정·공식 협약·신청·현금 지급·정산을 대행하거나 확정하지 않아요.

입력과 기기 처리

공고 확인 여부, 정부지원 상한 비율, 최소 현금 비율, 최대 현물 비율, 계산 단위, 요청 지원금, 준비 현금과 익명 현물 항목명·인정 예정액을 기기에서 처리해요. 실명·회사명·주민번호·계좌·연락처·증빙파일을 받지 않아요. 현물 항목명에도 개인정보를 적지 않도록 안내해요. 입력 원자료와 모의 결과를 운영 서버·광고·이용 분석 이벤트에 첨부해 보내지 않아요.

선택 저장과 복사

저장을 선택한 사업비 구성표만 이 기기에 남아요. 저장 해제로 이 앱의 새 기록만 지울 수 있으며 해제 후에도 현재 화면의 결과는 사용할 수 있어요. 기존 다른 기능의 저장 키는 삭제하지 않아요. 기기 저장소 정리·교체 시 복원되지 않을 수 있어요. 복사를 선택하면 입력 비율·계산 단위·필요 현금·현물 반영과 부족액·참고 안내·공식 출처를 클립보드에 써요. 클립보드 쓰기 권한만 사용하며 내용을 읽는 기능은 없어요.

무료 안내와 광고

계산 원리·비율의 분모·공식 참고 출처·확인할 조건은 무료예요. 공고·협약 미확인, 미입력, 유효하지 않은 비율·금액·단위는 광고 없이 알려줘요. 실제 연산을 마친 뒤 개인 사업비 구성표를 열 때 명시한 리워드 광고를 선택할 수 있어요. SDK 시청 완료 보상이 확인된 경우에만 열고 클릭·중도 종료·표시 실패만으로 열지 않아요. 같은 열어 둔 구성표와 저장본 수정에는 재광고를 요구하지 않아요. 배너는 표시 가능한 경우에만 제공해요.

외부 플랫폼

앱인토스·토스 광고 SDK는 광고 식별자·기기·접속·광고 이벤트 등 필요한 기술 정보를 자체 정책에 따라 처리할 수 있어요. 사업비·비율·현물 항목 등 입력 원자료를 광고 또는 이용 분석 이벤트에 첨부하지 않아요. 공식 출처를 열면 해당 사이트의 정책이 적용돼요.

계산의 한계

총사업비가 분모인 단순 구성을 대상으로 정부지원 상한·최소 현금·최대 현물을 함께 적용해요. 선택한 원·천원·만원 단위로 총사업비와 최소 현금은 올리고 현물 상한은 내려 계산해요. 입력 순서대로 한도 내 현물을 모의 반영하며, 실제 기관의 인정·집행 우선순위와 다를 수 있어요. 미반영 현물은 추가 현금 입금액이 아니에요. 세금·부가세·대출·별도 부담 비용·비용별 집행 한도를 자동 산정하지 않아요. 실제 공고·협약의 최신 비율·인정 범위·서식 처리·정산과 기관 결정이 우선해요. 참고 공고의 비율을 모든 사업에 적용하거나 현재 모집 중인 것으로 추천하지 않아요.

문의와 이용자의 권리

정보 처리·서비스 문의는 help@paran.app으로 보내 주세요. 문의에 사용자가 직접 제공한 이메일과 내용은 답변·문제 해결에 사용하고, 목적 달성 뒤 법령상 보존이 필요한 경우를 제외하고 정리해요. 제도·플랫폼 변경에 맞춰 기능과 안내를 수정할 수 있어요. 이 문서는 법령상 이용자의 권리를 제한하지 않아요.
