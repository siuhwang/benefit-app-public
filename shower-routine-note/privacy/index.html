제공 범위

냉난방지원금 체크는 정부기관과 제휴하지 않은 독립 참고 도구예요. 사용자가 고른 가구 조건과 이용방식을 2026 에너지바우처 기준과 대조해요. 공식 자격·선정·지급액·잔액을 조회하거나 신청을 대행하지 않아요. 실제 신청과 이용 전에는 관할 기관의 현재 안내를 확인해 주세요.

화면에서 처리하는 입력

세대원 수, 급여 수급 여부, 세대원 특성 기준의 해당 여부, 보장시설 여부, 다른 겨울철 지원과 바우처 이용방식 등을 사용자가 선택해요. 가구 조건은 현재 화면의 세션에서만 계산해요. 이름·주민등록번호·상세 주소·진단명·계좌번호·고객번호를 요구하지 않아요. 입력한 조건이나 금액 원자료를 운영 서버·광고·이용 통계에 보내지 않아요.

선택 저장과 삭제

사용자가 선택한 신청 준비 체크와 직접 입력한 선정 통지액·예산·사용 금액은 기기에 저장할 수 있어요. 준비 체크와 금액 기록은 각각 energy-voucher:prepare-checks:2026:v1, energy-voucher:manual-budget:2026:v1 저장 공간을 사용해요. 앱의 해당 저장 관리에서 기록을 지울 수 있어요. 이전 기능의 다른 저장 공간은 자동 삭제하거나 변환하지 않아요. 기기 저장소 정리·기기 교체 때 기록이 복원되지 않을 수 있어요.

무료 안내와 광고

제도 안내와 공식 출처는 광고 없이 볼 수 있어요. 광고 시청의 보상과 조건을 안내한 뒤 사용자가 시청을 선택하면 광고 플랫폼이 광고 식별자·기기·접속·광고 이벤트를 자체 정책에 따라 처리할 수 있어요. 정상 시청 완료 보상이 확인된 경우에만 해당 상세 결과가 열려요. 중도 종료·클릭·표시 실패만으로 결과가 열리지는 않아요. 상세 결과 화면에는 배너가 표시될 수 있어요.

외부 제공 환경

앱은 토스·앱인토스 환경과 광고 SDK에서 실행돼요. 공개 안내 문서는 Google Firebase Hosting과 Cloudflare를 통해 제공되며 문서 접속 과정의 IP 주소·브라우저·접속 정보는 각 제공자의 정책에 따라 처리될 수 있어요. 문서 주소에 가구 조건이나 금액을 붙여 보내지 않아요. 공식 출처를 열면 해당 기관 사이트의 정책이 적용돼요.

문의와 이용자 권리

문의는 help@paran.app으로 보내 주세요. 문의에 직접 제공한 이메일과 내용은 답변·문제 해결에 사용하고 목적 달성 후 관련 법령상 보존이 필요한 경우를 제외하고 정리해요. 선택 저장을 지워도 무료 제도 안내는 이용할 수 있어요. 이 안내는 관련 법령상 이용자의 권리를 제한하지 않아요.
