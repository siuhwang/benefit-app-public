서비스 범위

지원금 소득표는 정부·공공기관과 제휴하지 않은 독립적인 공표 기준 비교 도구예요. 2026년 및 2027년 1월 1일 적용으로 공표된 기준 중위소득과 생계·의료·주거·교육급여 소득 기준선을 보여줘요. 기관에서 확인한 보장가구원 수·월 소득인정액을 사용자가 입력하면 원 단위 차이와 같은 입력의 연도별 기준선을 비교해요. 지원 자격·선정·지급액·입금·신청을 확정하거나 대행하지 않아요.

입력과 기기 내 처리

선택한 공표 연도, 기관 기준 보장가구원 수, 금액의 확인 종류와 월 소득인정액을 기기에서 처리해요. 실명·주민번호·주소·계좌·전화번호·증명서·소득 및 재산 명세·건강보험료 세부값을 받지 않아요. 입력 원자료와 개인 비교표를 운영 서버·광고·이용 분석 이벤트에 첨부해 보내지 않아요. 기관이 확인한 소득인정액 대신 월급·건강보험료만 입력한 경우에는 개인 비교와 광고를 진행하지 않아요. 모르는 금액은 0원으로 간주하지 않아요.

무료 기준표와 리워드

연도·가구에 맞는 공표 기준표와 공식 출처 안내는 광고 없이 볼 수 있어요. 유효한 입력을 실제 분석한 뒤 개인 소득기준 비교표 1개를 열 때 리워드 광고를 선택해요. SDK 시청 완료 보상이 확인될 때만 개인 비교표를 열고 클릭·중도 종료·오류로는 열지 않아요. 열린 비교표의 입력 수정과 저장본 확인에는 재광고를 요구하지 않아요. 결과 배너는 표시 가능한 경우에만 제공해요.

선택 저장과 삭제

비교표 저장을 선택한 경우에만 해당 연도·가구원 수·소득인정액과 열림 상태를 이 기기의 새 전용 저장 키에 보관해요. 저장된 비교표를 수정하면 유효한 변경을 반영하고 저장 해제로 이 기능의 저장본만 지워요. 현재 화면의 입력과 다른 기존 기능의 저장 데이터는 지우지 않아요. 저장하지 않은 입력은 화면을 닫으면 사라질 수 있으며 기기·저장소를 정리하거나 교체하면 복원되지 않을 수 있어요.

복사와 외부 플랫폼

참고 비교표 복사를 선택하면 입력한 소득인정액·가구원 수와 개인 금액 차이·기준 범위·공식 출처를 클립보드에 써요. 클립보드 쓰기만 사용하고 읽지 않아요. 토스 광고 SDK는 기기·접속·광고 식별자·이벤트 등 필요한 기술 정보를 자체 정책에 따라 처리할 수 있어요. 개인 입력 원자료는 첨부하지 않아요. 공식 출처를 열면 해당 기관 사이트의 정책이 적용돼요.

비교의 한계

보장가구는 주민등록 등본 인원과 다를 수 있고 급여에 따라 소득평가·재산환산·가구 범위·공제·부양의무자·특례·연령 등 추가 요건이 달라요. 실제 기관에서 확인한 해당 급여의 월 소득인정액을 사용해요. 선 이내·초과·동일은 숫자 위치이며 수급 가능·불가를 뜻하지 않아요. 표시 비율은 반올림하지만 금액 차이는 원 단위로 대조해요. 8인 이상은 각 공표 표의 6인·7인 기준 차액을 더해요. 연도별 비교는 같은 입력의 명목 기준선 비교이며 소득·재산 변화와 재조사를 예측하지 않아요. 교육활동지원비 금액·시행일·세금·대출·다른 지원 자격을 계산하지 않아요. 최신 고시와 소관 기관의 실제 결정이 우선해요.

문의와 이용자의 권리

서비스와 정보 처리 문의는 help@paran.app으로 보내 주세요. 문의자가 직접 제공한 이메일·내용은 답변과 문제 해결에 사용하며, 목적 달성 뒤 법령상 보존이 필요한 경우를 제외하고 정리해요. 제도·플랫폼 변경에 맞춰 기능과 안내를 수정할 수 있어요. 이 문서는 법령상 이용자의 권리를 제한하지 않아요.
