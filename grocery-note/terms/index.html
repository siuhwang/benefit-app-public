서비스 범위

훈련지원금 출석은 정부기관이 운영하는 서비스가 아닌 독립적인 참고 도구예요. 2026 국민내일배움카드 일반훈련의 근로 상태·과정·다른 수당·출석률·하루 훈련시간을 선택해 일반 훈련장려금 기준을 비교해요. 최대 기준과 실제 개인 지급액을 구분하고, 자영업·국가기간전략·K-디지털 등 다른 유형은 별도 공식 확인을 안내해요. 기존 단위기간별 출석 기록·계획 비교도 보존하며, 공식 자격·선정·지급을 확정하거나 신청을 대행하지 않아요. 공식기관의 최신 기준과 개별 안내를 먼저 확인해요.

기기에서 처리하는 정보

간편조회에서 선택한 근로 상태·과정 구분·다른 수당 여부·출석률 구분·하루 훈련시간 구분은 기기에서 비교해요. 결과 저장을 직접 선택하면 간편조회 전용 공간(training-allowance:quick:2026:v1)에 선택 조건과 열람 여부를 저장해요. 간편조회 저장 해제는 이 저장만 지워요. 기존 과정명·단위기간·인정 출석일·실제 훈련 종료일의 기록 공간(training-attendance:2026:v1)은 별도로 보존하고 기존 화면에서 관리해요. 입력 원자료를 운영 서버·광고·분석 이벤트에 넣어 보내지 않아요. 기존 다른 기능의 저장 키는 변경하지 않아요.

광고와 이용 이벤트

공식 제도 안내와 출처는 무료로 볼 수 있어요. 보상과 조건을 확인하고 리워드 광고 시청을 선택할 수 있으며, SDK 시청 완료 보상이 확인된 경우에만 상세 기능이 열려요. 광고 중도 종료·클릭·표시 실패만으로 열리지 않아요. 같은 유효 저장 결과는 재시청 없이 열려요. 별도 유형·불확실 조건·현재 연도 미반영 시 추가 광고 없이 공식 확인 경로를 안내해요. 배너와 보상형 광고, 일반 버튼·완료 이벤트를 사용할 수 있어요.

외부 플랫폼

앱인토스·토스 광고 SDK는 광고 식별자, 기기·접속·광고 이벤트 정보를 자체 정책에 따라 처리할 수 있어요. 사용자가 입력한 조건·날짜·금액·출석 원자료는 광고 또는 이용 이벤트에 첨부하지 않아요. 공식 출처를 열면 해당 사이트의 정책이 적용돼요.

이름·주민등록번호·계좌번호 등 직접 식별 정보를 요구하지 않아요. 자유 입력에는 서비스에 필요한 과정명 등만 쓰고 개인 식별 정보는 넣지 말아 주세요. 기기 기록은 저장 해제 또는 앱·브라우저 저장소 정리 전까지 남을 수 있고, 기기 정리·교체 시 복원되지 않을 수 있어요.
