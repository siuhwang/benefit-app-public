시행일 2026년 10월 17일

서비스 범위

지원금 지출장부는 정부·공공기관과 제휴하지 않은 독립적인 개인 입력 장부예요. 사용자가 확인한 지원금·자부담 현금 예산, 사업기간과 실제 지출·연결 환불을 대조해요. 지원 자격·거래 적격·증빙 적격·기관 집행 인정·반환액·공식 정산·선정을 판단하거나 대행하지 않아요. 은행·기관과 거래를 연동하지 않아요.

기기에서 처리하는 입력

확인한 두 재원 예산, 사업 시작일·종료일, 익명 용도·날짜·지원금/자부담 금액·지출/환불 구분·환불 원거래 연결과 증빙 준비 상태를 기기에서 처리해요. 실명·거래처·주민번호·사업자번호·계좌·연락처·증빙파일을 받지 않아요. 용도에도 개인정보를 적지 않도록 안내해요. 입력 원자료와 개인 대조표를 운영 서버·광고·이용 분석 이벤트에 첨부해 보내지 않아요.

무료 입력과 선택 저장

거래 입력·수정·삭제, 기본 합계, 오류 안내와 공식 참고는 무료예요. 광고를 보기 전에도 유효한 입력 장부를 기기에 저장할 수 있어요. 저장 버튼으로 변경한 입력을 반영하고, 저장을 해제하면 이 기능의 새 저장 기록만 지워요. 현재 화면의 입력은 유지해요. 기존 다른 기능의 저장 키는 지우지 않아요. 저장하지 않은 내용이나 기기 저장소를 정리·교체한 기록은 복원되지 않을 수 있어요.

리워드와 배너

실제 대조 연산을 마친 뒤 월별 재원대조표를 열 때 안내된 리워드 광고를 선택해요. 지원/자부담의 순지출과 잔액·초과액, 월별 흐름과 기간 밖·증빙 준비 미완료 기록을 확인해요. SDK 시청 완료 보상이 확인된 경우에만 열고 클릭·중도 종료·오류만으로 열지 않아요. 이미 연 장부와 저장본의 수정에는 재광고를 요구하지 않아요. 결과 배너는 표시 가능한 경우에만 제공해요.

클립보드와 외부 플랫폼

복사를 선택하면 개인 예산·월별 순지출·잔액·확인 대상 건수와 계산 범위·공식 출처를 클립보드에 써요. 클립보드 쓰기만 사용하고 읽지 않아요. 토스 광고 SDK는 기기·접속·광고 식별자·이벤트 등 필요한 기술 정보를 자체 정책에 따라 처리할 수 있어요. 입력 원자료는 첨부하지 않아요. 공식 출처를 열면 해당 사이트의 정책이 적용돼요.

대조의 한계

순지출은 실제 기록의 지출에서 연결 환불을 뺀 산술 결과예요. 환불은 원지출의 재원별 남은 금액을 넘을 수 없고 원지출보다 빠른 날짜는 입력 오류로 알려줘요. 월을 넘겨 환불받으면 해당 월 순지출이 음수일 수 있어요. 사업기간 밖 거래도 실제 기록 합계에는 포함하고 별도 확인 대상으로 표시해요. 전액 환불해도 지출과 환불의 증빙 준비 상태를 각각 유지해요. 준비 완료는 사용자 확인일 뿐 기관의 적격 인정이 아니에요. 현물·이자·세금·부가세·대출·공식 반환액을 산정하지 않아요. 최신 공고·협약·기관 서식과 소관 시스템의 실제 결정이 우선해요.

문의와 이용자의 권리

서비스와 정보 처리 문의는 help@paran.app으로 보내 주세요. 사용자가 문의로 직접 제공한 이메일·내용은 답변과 문제 해결에 사용하고, 목적 달성 뒤 법령상 보존이 필요한 경우를 제외하고 정리해요. 제도·플랫폼 변경에 맞춰 기능과 안내를 수정할 수 있어요. 이 문서는 법령상 이용자의 권리를 제한하지 않아요.
