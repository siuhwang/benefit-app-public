서비스 범위

지원금 서류점검은 정부·공공기관과 제휴하지 않은 독립적인 방문 신청 준비 참고 도구예요. 기초연금·주거급여·국민취업지원제도의 공개 안내를 바탕으로 서류 준비와 기관 확인 항목을 정리해요. 자격·서류 완비·선정·지급을 확정하지 않고, 서류 발급·업로드·신청·제출을 대행하지 않아요.

입력과 선택 저장

급여 종류·방문 주체·배우자 여부·임대차 여부·기관 추가 안내 여부의 선택값을 기기에서 처리해요. 개인 사유·이름·주민번호·계좌·주소·소득 수치·실제 서류 파일을 받지 않아요. 저장을 선택한 프로그램별 조건과 항목별 확인 상태만 이 기기에 남아요. 준비표의 저장 해제로 해당 기록만 지울 수 있고 다른 프로그램의 저장본은 유지돼요. 저장 없이도 현재 준비표를 사용할 수 있어요. 기기 저장소 정리·교체 시 기록은 복원되지 않을 수 있어요.

광고와 무료 안내

기본 서류 안내와 공식 출처는 무료예요. 입력 조건의 분석 뒤 개인 준비표를 열 때 보상·조건을 확인하고 리워드 광고를 선택할 수 있어요. SDK 시청 완료 보상이 확인된 경우에만 준비표를 열어요. 클릭·중도 종료·오류만으로 열리지 않아요. 같은 열어 둔 준비표와 저장한 준비표의 조건 수정에는 재광고를 요구하지 않아요. 배너는 표시 가능한 경우에만 제공해요.

외부 서비스와 정보 처리

입력 원자료와 확인 상태를 운영 서버·광고·이용 분석 이벤트에 첨부해 보내지 않아요. 앱인토스·토스 광고 SDK는 광고 식별자·기기·접속·광고 이벤트 등 광고 제공에 필요한 기술 정보를 자체 정책에 따라 처리할 수 있어요. 공식 출처를 열면 해당 사이트 정책이 적용돼요. 준비표 복사를 선택하면 공개 서류명·선택한 급여·준비 상태·기관 확인 질문과 출처를 기기 클립보드에 복사해요. 계좌나 신분 정보는 담기지 않아요.

정확성과 변경

공식 사실 확인일과 적용 범위를 앱에서 확인할 수 있어요. 개인 상황과 기관 조회 가능 여부에 따라 실제 서류가 달라질 수 있으므로, 발급 전 접수기관의 최신 안내를 확인해 주세요. 공적 자료로 조회 가능한 서류를 무조건 발급할 필요는 없어요. 제도·플랫폼 변경에 맞춰 기능과 안내를 수정할 수 있어요.

문의와 이용자의 권리

정보 처리·서비스 문의는 help@paran.app으로 보내 주세요. 문의에 사용자가 직접 제공한 이메일과 내용은 답변·문제 해결에 사용하며 목적 달성 후 관련 법령상 보존이 필요한 경우를 제외하고 정리해요. 이 안내는 법령상 이용자의 권리를 제한하지 않아요.
