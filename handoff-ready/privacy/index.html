시행일 2026년 10월 17일

서비스 범위

주거지원금 계산은 정부·공공기관과 제휴하지 않은 독립 참고 계산 도구예요. 2026년 일반 임차급여의 공표 기준과 확인한 개인 가구·계약 조건을 대조해요. 수급 자격·선정·입금액·신청 완료나 이사·계약 선택을 보장·추천하지 않아요. 기관의 소득·재산 및 주택조사와 실제 결정이 우선해요.

기기에서 처리하는 입력

기관에서 확인한 보장가구원 수와 주거급여 월 소득인정액, 일반 임차 조건 확인, 익명 조건 이름과 광역급지·보증금·월세·선택 관리비·필요 시 공식 확인 기준임대료를 기기에서 처리해요. 주소·실명·임대인·주민번호·계좌·연락처·계약서·재산명세를 받지 않아요. 조건 이름에도 개인정보를 넣지 않아요. 입력 원자료나 개인 대조표를 운영 서버·광고·이용 분석 이벤트에 첨부하지 않아요.

무료 기능과 리워드

기본 기준임대료와 보증금 환산 등 참고 산식, 입력·수정·추가·삭제·기기 저장과 공식 안내는 무료예요. 유효하게 확인한 값을 실제 분석한 뒤 개인 주거급여 대조표 1개를 열 때 리워드 광고를 선택해요. SDK 시청 완료 보상이 확인된 경우만 열고 클릭·중도 종료·오류로 열지 않아요. 같은 열린 표의 수정과 유효 저장본 확인에는 재광고를 요구하지 않아요. 2026년 자료를 다음 연도로 자동 적용해 새 리워드 분석을 진행하지 않아요. 결과 배너는 표시 가능한 경우에만 제공해요.

선택 저장·해제

저장 버튼을 선택하면 현재 입력과 결과 열림 상태를 이 기능의 새 전용 저장 키에 보관해요. 상세 대조표를 열기 전에도 입력을 무료로 저장하고 복원할 수 있어요. 저장을 선택한 상태에서 유효한 변경을 반영하고, 저장 해제로 이 기능 저장본만 지워요. 현재 입력과 기존 다른 기능의 기록은 지우지 않아요. 저장하지 않거나 기기·저장소를 정리·교체한 자료는 복원되지 않을 수 있어요.

복사와 외부 플랫폼

복사를 선택하면 가구원 수·확인 소득·계약 금액과 개인 참고 산식·한계·공식 출처를 클립보드에 써요. 쓰기만 사용하고 클립보드를 읽지 않아요. 토스 광고 SDK는 기기·접속·광고 식별자·이벤트 등 필요한 기술 정보를 자체 정책에 따라 처리할 수 있어요. 개인 입력 원자료는 첨부하지 않아요. 공식 출처를 열면 해당 기관 사이트의 정책이 적용돼요.

계산 범위와 한계

2026년 일반 임차 대상 조건의 보증금 월 환산·기준임대료 상한·소득에 따른 자기부담·최소급여·월차임 우선 충당과 보증금분을 참고 계산해요. 관리비는 급여 산식에서 제외하고 개인 부담에만 더해요. 미확인 소득·보증금·월세를 0으로 가정하지 않고, 관리비 미입력은 미확인으로 표시해요. 실제임차료 0원 계약에 최소급여를 자동 산정하지 않아요. 10인 이상 기준임대료는 재귀값을 추측하지 않고 공식 확인 금액을 직접 사용해요. 자가 수선유지급여·청년분리·사용대차·시설·직계혈족 임대차·공공임대 특수계약·연체대납·특례·중복지원·대출·세금·실제 신청은 산정하지 않아요. 실제 임차료 인정·변경·지원 조건에 따라 결정액은 달라져요. 저장된 2026년 결과는 해당 연도 참고 기록이며 현재 연도 확정 결과가 아니에요.
