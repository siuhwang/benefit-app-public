서비스 범위

육아지원금 달력은 정부기관이 운영하는 서비스가 아닌 독립적인 참고 도구예요. 생일과 현재 돌봄 방식으로 2026 부모급여의 연령별 기본지원 기준·돌봄별 확인사항·공식 신청경로를 안내해요. 생일만으로 개인 현금 차액을 확정하지 않아요. 기존 현금·보육료 참고 일정과 실제 수령 기록 관리도 유지하며, 공식 자격·선정·지급을 확정하거나 신청을 대행하지 않아요. 공식기관의 최신 기준과 개별 안내를 먼저 확인해요.

기기에서 처리하는 정보

간편조회는 생일·돌봄 방식 두 가지를 기기에서 계산해요. 결과 저장을 선택하면 간편조회 전용 저장 공간(parent-benefit:quick:2026:v1)에 입력과 열람 여부가 남아요. 간편조회 저장 해제는 이 저장만 지워요. 기존 달력의 출생일·돌봄 방식·보육료·신청일·입금 기록도 기기에서 처리하고, 기존 달력 저장 공간(parent-benefit:calendar:2026:v1)과 분리해 보존해요. 각 화면의 저장 해제 기능으로 해당 기록을 지울 수 있어요. 입력 원자료를 운영 서버·광고·분석 이벤트에 넣어 보내지 않아요. 기존 다른 기능의 저장 키는 변경하지 않아요.

광고와 이용 이벤트

공식 제도 안내와 출처는 무료로 볼 수 있어요. 보상과 조건을 확인하고 리워드 광고 시청을 선택할 수 있으며, SDK 시청 완료 보상이 확인된 경우에만 상세 기능이 열려요. 광고 중도 종료·클릭·표시 실패만으로 열리지 않아요. 같은 유효 저장 결과를 다시 볼 때는 광고를 반복 요구하지 않아요. 배너와 보상형 광고, 일반 버튼·완료 이벤트를 사용할 수 있어요.

외부 플랫폼

앱인토스·토스 광고 SDK는 광고 식별자, 기기·접속·광고 이벤트 정보를 자체 정책에 따라 처리할 수 있어요. 사용자가 입력한 조건·날짜·금액·출석 원자료는 광고 또는 이용 이벤트에 첨부하지 않아요. 공식 출처를 열면 해당 사이트의 정책이 적용돼요.

정보 최소화와 보관

이름·주민등록번호·계좌번호 등 직접 식별 정보를 요구하지 않아요. 간편조회에는 이름·연락처·계좌번호 입력란이 없어요. 기기 기록은 저장 해제 또는 앱·브라우저 저장소 정리 전까지 남을 수 있고, 기기 정리·교체 시 복원되지 않을 수 있어요.

문의와 이용자의 권리

정보 처리 또는 서비스 문의는 help@paran.app으로 보내 주세요. 문의에 사용자가 직접 제공한 이메일과 내용은 답변·문제 해결에 사용하며, 목적 달성 뒤 관련 법령상 보존이 필요한 경우를 제외하고 정리해요. 선택적 기기 저장을 해제하고도 무료 안내를 사용할 수 있어요.

서비스의 변경과 정확성

공식 제도와 플랫폼 변경에 맞춰 기능·기준을 수정할 수 있어요. 기준일과 적용 범위를 화면에서 확인해 주세요. 입력 오류·정산·행정 처리 차이를 고려해 실제 행동 전 공식기관에서 확인해요. 이 안내는 법령상 이용자의 권리를 제한하지 않아요.
